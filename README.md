# DocGuard-AI

**Automated Documentation Drift Detection**

DocGuard-AI is an open-source project designed to identify outdated documentation caused by changes in source code.

## Problem Statement

**Problem 05 – Automated Documentation Drift Detection**

Documentation often becomes outdated when developers modify source code without updating the corresponding documentation.

Examples include:
- Renamed configuration flags.
- Changed default values.
- Modified API parameters.
- Removed features that are still referenced in documentation.

## Our Objective

Build a tool that detects inconsistencies between source code and project documentation.

## Planned Features

- Analyze code changes.
- Identify related documentation.
- Detect outdated configuration descriptions.
- Find incorrect API references and defaults.
- Highlight potentially outdated documentation sentences.
- Connect documentation issues to relevant code changes.
- Support GitHub Pull Request workflows.
